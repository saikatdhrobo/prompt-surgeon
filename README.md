# Prompt Surgeon

Elite prompt-engineering framework for diagnosing and optimizing prompts across modern LLMs.

Prompt Surgeon transforms weak, vague, or inefficient prompts into high-performance prompts optimized for reasoning, creativity, research, coding, automation, and agentic workflows.

---

## Features

- Prompt diagnosis
- Hallucination reduction
- Cross-model optimization
- Structured reasoning prompts
- Agentic workflows
- Prompt compression
- Research-mode prompting
- Modular prompt architectures
- Advanced prompt reconstruction

---

## Supported Models

- ChatGPT
- Claude
- Gemini
- Kimi
- DeepSeek

---

## Modes

### `/precision`
Maximum clarity, reasoning quality, and verification.

### `/creative`
Optimized for ideation, storytelling, and creativity.

### `/research`
Structured evidence gathering and analysis.

### `/agent`
Autonomous workflow and agentic task execution.

### `/minimal`
Compressed high-signal prompts for token efficiency.

---

## Usage

Copy the contents of `MASTER_PROMPT.md` into:

- ChatGPT Custom GPT Instructions
- Claude Project Instructions
- Gemini Gems
- Kimi Skill Creator
- Any LLM system prompt field

Then interact normally.
